# STM32F411 멀티태스킹 펌웨어 부트캠프 커리큘럼

**대상 보드**: NUCLEO-F411RE (Cortex-M4, 100MHz, 512KB Flash, 128KB RAM)
**사용 환경**: STM32CubeIDE + HAL 라이브러리, FreeRTOS(커널 10.x), Zephyr LTS
**교육 방식**: 오전 이론 2h + 오후 실습 6h (하루 8h × 5일 × 3주 = 120h)
**주제 축**: 하나의 MCU에서 "여러 기능을 동시에" 동작시키는 방법론 — 폴링 → 인터럽트 → 타이머 → SysTick → FreeRTOS → Zephyr

---

## 1주차 — Bare-metal 기초부터 인터럽트/타이머까지

### Day 1 (8h): 개발 환경 구축과 GPIO / 폴링 방식의 한계

**오전 (이론 2h)**
- MCU 구조 이해: Cortex-M4 코어, 클록 트리(HSI → PLL 100MHz), 메모리 맵
- NUCLEO-F411RE 보드 분석: LD2(PA5), USER 버튼(PC13), ST-LINK, UART(VCP)
- 개발 흐름: CubeMX → 코드 생성 → HAL API 구조

**오후 (실습 6h)**
- 실습 1-1: LED 점멸(HAL_Delay 사용) + 버튼으로 LED 토글 (폴링 방식)
- 실습 1-2: UART printf 디버깅 환경 구성 (USART2, 115200bps)
- 실습 1-3: **실패 경험 만들기** — `HAL_Delay` 기반으로 "LED 점멸 1초 + 버튼 즉시 반응 + 초음파센서 거리 출력" 3개 동시 수행 시도
- **학습 포인트**: 폴링 방식이 왜 블로킹되는지, `HAL_Delay()`가 왜 멀티 기능의 적인지 몸으로 체감

### Day 2 (8h): EXTI 인터럽트 — 즉시 반응성 확보

**오전 (이론 2h)**
- NVIC 구조: 우선순위(priority/preemption), IRQ 핸들러 흐름
- EXTI 라인 개념: GPIO → EXTI → NVIC 경로
- 인터럽트 서비스 루틴(ISR) 작성 규칙: 짧게! volatile! 플래그 패턴!

**오후 (실습 6h)**
- 실습 2-1: 버튼 EXTI 인터럽트로 LED 토글 (채터링 관찰 → 디바운스의 필요성 이해)
- 실습 2-2: ISR에서 플래그 set → 메인 루프에서 처리하는 "ISR + 워커" 패턴
- 실습 2-3: 인터럽트 중첩 실험 — 우선순위를 바꿔가며 동작 관찰
- **체크포인트**: Day 1의 3기능 동시 수행 과제를 "메인 루프 + ISR" 구조로 재도전 → 여전히 LED 점멸(지연) 문제가 남음을 확인

### Day 3 (8h): 하드웨어 타이머 — 정밀한 시간 제어

**오전 (이론 2h)**
- TIM2~TIM5(32bit 일반 타이머), TIM6/7(기본), TIM1/9/10/11(고급) 구조
- 프리스케일러/ARR 계산: `Update 주기 = Fclk / ((PSC+1) × (ARR+1))`
- 업데이트 인터럽트 vs 타이밍 채널(Output Compare)의 차이

**오후 (실습 6h)**
- 실습 3-1: TIM2 업데이트 인터럽트로 정확한 1ms/10ms/100ms 틱 생성, LED 점멸
- 실습 3-2: 소프트웨어 멀티타이머 만들기 — 하나의 타이머 인터럽트에서 카운터 3개로 "기능 A 1초 / 기능 B 200ms / 기능 C 10ms" 동시 구동
- 실습 3-3: TIM 인터럽트 + EXTI + UART 조합 — Day 2의 3기능 과제를 타이머 기반으로 완성
- **학습 포인트**: "하드웨어 타이머가 곧 멀티태스킹의 뼈대"라는 감각 확보

### Day 4 (8h): 타이머 활용 기술 — PWM, IC, DMA

**오전 (이론 2h)**
- PWM 원리(듀티비, 주파수)와 활용 예: 서보모터, LED 밝기, 부저
- Input Capture로 외부 신호 주기/듀티 측정
- DMA 개념: CPU 개입 없는 UART/타이머 데이터 전송

**오후 (실습 6h)**
- 실습 4-1: TIM PWM으로 LED 페이드인/아웃 + 서보모터 각도 제어
- 실습 4-2: Input Capture로 외부 신호 주기 측정
- 실습 4-3: UART + DMA로 블로킹 없이 문자열 송신 — ISR 부하 줄이기
- 미니 과제: **PWM 서보 + 버튼 인터럽트 + UART 로그 동시 동작** 데모

### Day 5 (8h): SysTick 기반 스케줄링 — 1주차 종합

**오전 (이론 2h)**
- SysTick 타이머: 코어 내장 24비트 다운카운터, HAL_GetTick()의 원리
- 슈퍼루프 + 시간 분할 스케줄링(Cooperative) 패턴
- 비선점 협동 스케줄러의 장점(초심자 친화)과 한계(긴 작업이 전체를 막음)

**오후 (실습 6h)**
- 실습 5-1: HAL_GetTick()으로 non-blocking 딜레이 작성(`delay_until` 패턴)
- 실습 5-2: 직접 만드는 미니 스케줄러 — 태스크 테이블(함수포인터 + 주기) 구조체 배열, 시간 분할 실행
- 실습 5-3: 스케줄러에 4개 태스크 등록: LED PWM / 버튼 / 센서 폴링 / UART 리포트
- 1주차 평가: 폴링 → 인터럽트 → 타이머 → SysTick 각 단계별 장단점 발표(개인 5분)
- **단계별 다이어그램 정리**: 각 방식의 CPU 점유율 / 응답성 / 복잡도 비교표 작성

## 2주차 — FreeRTOS 본격 학습

### Day 6 (8h): RTOS 개념과 첫 태스크

**오전 (이론 2h)**
- RTOS란? 선점형 스케줄링, 문맥 교환(Context Switch), 우선순위 개념
- FreeRTOS 아키텍처: 태스크, 스케줄러, Tick (CubeMX에서 SysTick이 FreeRTOS 틱이 됨)
- CubeMX에서 FreeRTOS 활성화 방법

**오후 (실습 6h)**
- 실습 6-1: 두 태스크 생성 — LED 점멸 태스크 vs UART 메시지 태스크, 각각 다른 주기로 vTaskDelay
- 실습 6-2: 우선순위 실험 — 동일 우선순위(타임슬라이싱) / 다른 우선순위(선점) / taskYIELD 관찰
- 실습 6-3: 스택 오버플로우 고의 발생 + uxTaskGetStackHighWaterMark로 진단
- **학습 포인트**: "while(1) 하나가 여러 while(1)로 갈라진다" — 논블로킹 태스크 작성 훈련

### Day 7 (8h): 태스크 간 통신 — 큐와 세마포어

**오전 (이론 2h)**
- 데이터 흐름 설계: ISR → 태스크 전달이 RTOS 설계의 핵심
- Queue: 복사 기반 메시지 전달, 블로킹 타임아웃
- 세마포어(카운팅/바이너리) vs 뮤텍스 — 차이를 정확히 구분하기

**오후 (실습 6h)**
- 실습 7-1: 버튼 EXTI ISR → 큐 → 소비 태스크로 이벤트 전달
- 실습 7-2: UART 수신 인터럽트 → 큐 → 처리 태스크로 명령어 파싱
- 실습 7-3: 서보모터 제어 태스크 + 명령 태스크 — 명령 큐로 목표 각도 변경
- 미니 과제: **"UART로 명령을 받아 LED/서보/센서 로그를 제어하는 미니 콘솔"** 완성

### Day 8 (8h): 이벤트 기반 통합 및 리소스 관리

**오전 (이론 2h)**
- 이벤트 그룹, 태스크 노티피케이션(가장 가벼운 ISR→태스크 신호 방식)
- 공유 자원 보호: 뮤텍스로 UART 출력 경쟁 해결
- 실시간 성능 지표: 컨텍스트 스위치 비용, Priority Inversion

**오후 (실습 6h)**
- 실습 8-1: 5개 태스크가 동시에 printf → 메시지 오염 재현 → 뮤텍스로 해결
- 실습 8-2: Task Notification을 이용한 센서 데이터 알림 (고성능 패턴 체험)
- 실습 8-3: SysTick 자체 구현 확인 — HAL_GetTick이 FreeRTOS 틱에서 오는지 트레이싱
- 실습 8-4: 1주차에서 만든 "SysTick 미니 스케줄러"를 FreeRTOS 태스크로 1:1 마이그레이션 → 코드 비교 데모

### Day 9 (8h): 소프트웨어 타이머 + Watchdog / 저전력

**오전 (이론 2h)**
- FreeRTOS 소프트웨어 타이머: 타이머 서비스 태스크, 원샷/주기형
- Idle 태스크와 vApplicationIdleHook 활용
- Tickless Idle로 저전력 모드 진입 개념

**오후 (실습 6h)**
- 실습 9-1: 소프트웨어 타이머 3개(100ms PWM 갱신 / 1초 로그 / 동적 생성 타이머)
- 실습 9-2: Idle 훅에서 틱 카운트로 CPU 점유율 추정
- 실습 9-3: Watchdog(IWDG) + 태스크 펫(pet) 패턴 — 멀티 태스크 안정성 설계
- 종합 미니 과제: **멀티 기능 데모 1.0** — 서보 + 센서 로깅 + 버튼 + UART 콘솔 명령, 모든 기능이 독립 태스크

### Day 10 (8h): 디버깅/분석 도구 + 2주차 평가

**오전 (이론 2h)**
- RTOS 디버깅: 런타임 태스크 통계(vTaskGetRunTimeStats), trace 도구(SystemView 개념 소개)
- 우선순위 설계 원칙: Rate Monotonic 개념 소개
- 메모리 계획: heap_1~heap_5 힙 모델, 스택 크기 계산법

**오후 (실습 6h)**
- 실습 10-1: 런타임 통계로 태스크별 CPU 점유율 측정 리포트 출력
- 실습 10-2: 의도적 Priority Inversion → 뮤텍스로 해결 관찰
- 2주차 평가: 멀티 기능 데모 1.0 리팩터링 시험 (2시간) — 더 깔끔한 아키텍처로 재도전
- 개인 발표: FreeRTOS 설계하면서 배운 3가지

## 부록: 교육 설계 포인트

| 구분 | 방식 | 핵심 메시지 |
|---|---|---|
| 폴링 (Day1) | `while(1)+HAL_Delay` | 블로킹 = 멀티 기능 불가 |
| 인터럽트 (Day2) | EXTI+NVIC | 즉시 반응, 하지만 복잡도 증가 |
| 하드웨어 타이머 (Day3-4) | TIM/PWM/IC/DMA | 멀티타이머로 정확한 병렬 태스크 |
| SysTick 스케줄러 (Day5) | 시간 분할 루프 | RTOS의 전신을 직접 만들어보기 |
| FreeRTOS (Day6-10) | 선점형 태스크 | 산업 표준, 실무 밀도 높음 |
| Zephyr (Day11-13) | DTS+서브시스템 | 표준화된 대형 RTOS 생태계 |
| 프로젝트 (Day14-15) | 선택 주제 통합 | 5가지 방식을 상황에 맞게 선택하는 역량 |

**권장 사전 준비물**: C 언어(포인터/구조체/함수포인터) 기초, NUCLEO-F411RE + 브레드보드 + 저항 + 점퍼선, (선택) 초음파/서보/온습도(DHT22) 센서 키트
